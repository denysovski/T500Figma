# Hlavní uživatelské toky

1. **Objevování žebříčku:** Splash → Onboarding → Domů → TOP 500 → Hledat / Filtry (Žánr, Země, Jazyk) / Řazení → Detail.
2. **Detail umělce (Drake):** Detail → Streamy (Lead / Featured / Sólo) → Podobní umělci.
3. **Porovnání:** Porovnat (přednastaveno Drake + Taylor Swift) → tlačítko *Porovnat* → výsledek s metrikami.
4. **Statistiky:** Statistiky → Žánr (Hip-Hop) → Země původu → Víš, že… (čísla v kontextu).
5. **Země na hlavu:** Statistiky → Země na hlavu → Irsko (demografie, streamy na 1 mil. obyvatel).
6. **Osobní část:** Oblíbené → Můj přehled → Nastavení (zde jsou uvedeny zdroje dat).
7. **Chybové stavy:** 404, Chyba/Offline, Umělec nenalezen, Bez výsledků, Načítání.
