# Hlavní uživatelské toky

1. **Objevování žebříčku:** Splash → Onboarding → Domů → TOP 500 → Hledat / Filtry (Žánr, Země, Jazyk, Typ umělce, Pohlaví) / Řazení → Filtrované výsledky → Detail.
2. **Detail umělce (Drake):** Detail → Streamy (Lead / Featured / Sólo) a Podobní umělci. Do detailu vede proklik pouze u Drakea.
3. **Porovnání:** Detail Drakea → Porovnat → Porovnání Drake vs. Taylor Swift. Výběr umělců je dostupný z Oblíbených (Porovnat výběr).
4. **Statistiky:** Statistiky (žánry) → Žánr Hip-Hop → Detail Drakea. Země původu se otevírá z Domů a Víš, že… ze Země na hlavu.
5. **Země na hlavu:** Statistiky → Země na hlavu → Irsko (demografie, streamy na 1 mil. obyvatel).
6. **Osobní část:** Oblíbené → Můj přehled. Nastavení (zde jsou uvedeny zdroje dat) se otevírá ozubeným kolem v záhlaví.
7. **Chybové stavy:** Bez výsledků (→ TOP 500), Načítání, 404 (→ TOP 500), Chyba načtení · Offline (→ Načítání), Umělec nenalezen (→ Hledat).
